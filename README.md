# WebMCP Kit

Claude Code plugin that adds [WebMCP](https://github.com/webmachinelearning/webmcp) tools to a web app: it reads your repo, proposes a reviewable tool plan, implements the tools against `@agentlane/webmcp`, and verifies them in a browser.

## Install

```
/plugin marketplace add nekuda-ai/webmcp-kit
/plugin install webmcp-kit@nekuda
```

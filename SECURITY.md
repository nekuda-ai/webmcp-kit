# Security policy

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/nekuda-ai/webmcp-kit/security/advisories/new). Do not open a public issue for a security vulnerability.

WebMCP Kit runs locally. Its Explorer listens on localhost, and the plugin does not send repository contents, routes, or schemas to a hosted Nekuda service.

Security fixes are made against the latest release and the `main` branch.
